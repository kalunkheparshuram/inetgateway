# Code of conduct

We want this project to be a respectful, useful place for everyone who contributes or asks for help.

**Do:** be courteous and patient; give specific, kind feedback; assume good faith; accept that maintainers are volunteers; keep discussion on the technical topic.

**Don't:** harass, insult, threaten or demean anyone; publish other people's private information (including their network captures or keys); use the project to discuss attacking networks you do not own or administer; spam.

This applies in issues, pull requests, discussions and any space where the project is represented.

**Enforcement.** Maintainers may edit or remove comments, close threads, and block people who break these rules. To report a problem, use the repository's private reporting channel
(see [SECURITY.md](SECURITY.md)) or contact a maintainer through their GitHub profile. Reports are handled in confidence as far as practical.

This is a short, original code of conduct written for this project. Maintainers may replace it with a standard one (such as the Contributor Covenant) at any time.
